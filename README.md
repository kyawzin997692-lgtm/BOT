# Telegram Bot for Ruijie Portal Brute Force & Scanning

This is a 24/7 Telegram bot designed to run on Render, featuring Tor proxy support, asynchronous scanning, and GitHub integration for user authentication and result storage.

## Features
* Telegram Bot Interface with Admin and User commands
* Tor Proxy Pool support with auto-rotation
* OCR Captcha Solving via `ddddocr`
* GitHub API integration for storing keys and results
